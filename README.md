# AI Email Generator

AI Email Generator is a simple web application built using Python, Streamlit, and OpenAI API. This project helps users generate professional and well-structured emails automatically using Artificial Intelligence.

The application allows users to enter an email topic and select different tones such as Professional, Friendly, or Formal. Based on the user input, the AI generates high-quality email content instantly.

## Features

- AI-powered email generation
- Multiple email tone options
- Simple and interactive user interface
- Fast response generation using OpenAI API
- Beginner-friendly project structure

## Technologies Used 

- Python
- Streamlit
- OpenAI API

## Project Modules

### Module 1 - Email Generation
- User enters email topic
- User selects email tone
- AI generates complete email content
